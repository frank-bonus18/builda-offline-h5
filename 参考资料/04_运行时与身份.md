<h2 id="能力详解">能力详解与使用规范</h2>

      
<h3>runtime：就绪、退出、避让、语言</h3>
      <ul>
        <li><strong><code>runtime.ready()</code> 必须在游戏最开始调用</strong>：放在入口脚本/首个场景的第一件事，不要等资源加载完再调，并确保任何启动路径都能调到它。宿主靠它确认游戏活着：页面加载 <strong>30 秒内没收到 ready，游戏会被强制关闭</strong>。mock 版页面加载 15 秒未收到 ready 会在 console 警告提醒。</li>
        <li><strong><code>runtime.quit()</code> 通常不用调</strong>：平台胶囊菜单自带退出入口。调用它不会直接关游戏，而是调起平台通用暂停/退出页，去留由玩家决定。</li>
        <li><strong><code>runtime.safeArea()</code></strong>（同步裸返回）：安全区四边 inset <code>{top, right, bottom, left}</code>，单位 CSS 像素，无刘海设备全 0。背景可全屏，关键 HUD / 按钮必须避开。游戏视口分辨率与窗口不一致时先按比例换算（inset × 视口宽 ÷ 窗口 CSS 宽）再应用。宿主会在方向变化时更新，可在 resize 回调里每次现取。</li>
        <li><strong><code>runtime.capsuleMenuRect()</code></strong>（同步裸返回）：平台右上角悬浮胶囊按钮矩形 <code>{top, right, width, height}</code>（<code>top</code>/<code>right</code> 是距视口上/右边缘的 inset）。可点击 UI 不要摆进这个矩形；自己的顶部按钮可取其 <code>top</code>/<code>height</code> 对齐排在左侧。<code>width/height</code> 为 0 表示无悬浮入口、无需避让。</li>
        <li><strong><code>runtime.language()</code></strong>（同步裸返回 String，绝不返回空串，兜底 <code>"en"</code>）：平台只给<strong>裸语言码</strong>（<code>zh</code>、<code>en</code>，不带区域变体，不会出现 <code>zh-CN</code>），唯一例外西语为 <code>es-419</code>。不要做简繁分支或按区域细分文案。匹配语言包按三级回退：精确匹配 → 语言前缀降级（<code>es-419</code> → <code>es</code>）→ 游戏默认语言。启动时读一次即可；宿主支持运行中切语言，在切场景等节点重读即可跟上，无需轮询。</li>
      </ul>

      
<h3>whoami 与 requestToken</h3>
      <ul>
        <li><code>whoami()</code> 返回 <code>{id, name, avatar?}</code>。真机由宿主提供真实玩家，游戏<strong>不感知登录、不处理任何 token</strong>；本地 mock 返回 URL 参数指定的假玩家。</li>
        <li><code>requestToken()</code> 返回 <code>{token, expiresAt}</code>（Unix 秒）：<strong>game-scoped 短期 token</strong>，绑定当前游戏 × 当前玩家 × 有限时效，供游戏逻辑层直连需要鉴权的 Builda 服务（如 Builda Online），<strong>不是完整登录态</strong>。临近 <code>expiresAt</code> 自行重新请求。本地 mock token 是伪造形态，连不上真实服务，只用于跑通过期刷新逻辑。</li>
      </ul>
      <blockquote>
        <p><strong>红线：</strong>token 只在内存持有，<strong>严禁</strong>写入 privateKV、本地文件、URL、日志或存档。</p>
      </blockquote>

      
<h3>getRoleInfo 与 getServerTime：他人公开资料、权威时间</h3>
      <ul>
        <li><code>getRoleInfo(roleIds)</code> 批量查询<strong>其他玩家</strong>的公开昵称与头像，返回 <code>{roleId: {userName, userImg}}</code> 映射：有 key 表示本次查到，没有 key 表示本次没查到，昵称或头像可以是空字符串。<code>roleId</code> 是正整数十进制字符串，单次最多 32 个；排行榜、联机房间里的对手信息都用它展示（<code>whoami()</code> 只给当前玩家自己）。Godot 侧 <code>builda.get_role_info(role_ids)</code>，Unity 侧 <code>BuildaSDK.GetRoleInfo(roleIds, callback)</code>。</li>
        <li>SDK 会把 50ms 内的多次查询合并去重，成功资料在当前游戏页面内缓存 30 分钟、最多 512 项，因此每个玩家只查一次即可，<strong>不要高频轮询</strong>，也不要把缺 key 当成网络错误反复重试。本地 mock 返回确定性假资料，真机才访问 Builda。</li>
        <li><code>getServerTime()</code> 返回 <code>{serverTimeMs}</code>：Builda 服务端的权威时间（Unix 毫秒）。每日任务刷新、限时活动、赛季倒计时、防止改机器时间刷奖励，都应以它为准，<strong>不要用设备本地时间</strong>。Godot 侧 <code>builda.get_server_time()</code>，Unity 侧 <code>BuildaSDK.GetServerTime(callback)</code>。</li>
        <li>SDK 首次调用时向 Builda 对一次时钟（最多等 1 秒），之后用本地单调时钟推算并定期重新同步，所以连续调用不会产生网络请求；对时失败且没有可用时钟时返回 <code>NETWORK</code> 失败态，游戏应稍后重试或先按“时间未知”处理。它面向秒级业务判定，不是毫秒级对时，也不能替代服务端对奖励、排行等结果的校验。本地 mock 用本机时间推算。</li>
      </ul>
      <pre><code>const profiles = await Builda.getRoleInfo(["11299825", "11299826"]);
if (profiles.ok) {
  const p = profiles.data["11299825"];           // 可能为 undefined：本次没查到
  showOpponent(p ? p.userName : "玩家", p ? p.userImg : "");
}

const now = await Builda.getServerTime();
if (now.ok &amp;&amp; now.data.serverTimeMs &gt;= dailyResetAtMs) refreshDailyTasks();</code></pre>
      <blockquote>
        <p><strong>规范：</strong>公开资料只用于当前会话内展示，不要写入存档或拼成自己的玩家库；时间判定以 <code>serverTimeMs</code> 为准，但涉及奖励、排名、支付的最终结果仍由平台服务端校验。</p>
      </blockquote>

      
<h3>playerData：本人存储观察</h3>
      <p><code>Builda.playerData.getMany(["coins"])</code> 要求非空 keys；<code>listKeys()</code> 返回目录 <code>data.meta.keys</code>，<code>values={}</code>。两者 data 都是 <code>{meta,values,source}</code>。已发布游戏联网登录时不进房也可读取本人数据，草稿试玩不支持。Godot：<code>player_data_get_many</code> / <code>player_data_list_keys</code>；Unity：<code>PlayerDataGetMany</code> / <code>PlayerDataListKeys</code>。</p>
      <p>这是可能滞后的非权威观察，revision/source 不保证最新。发奖、扣减、偷菜和支付由 Online 游戏服务器动作裁决；不能从观察整档覆盖存档，后续旧读不能推翻正式动作结果或触发重放。失败不是空档或零余额；保留旧展示时标明“可能滞后/本次刷新失败”。</p>
      <p>缺 key 返回 null，tombstone 是 value=null 的非 null 项。value 保留 <code>{type,data}</code> 类型树：int64/revision 是十进制字符串，bytes 是 Base64，object 递归包含 typed 字段，schemaVersion 为 uint32 数值或 null；不把 int64 转 Number。它与 privateKV 独立，服务端秘密不能放在可读字段。本地 mock 为独立 coins=0 fixture，不发送真实 HTTP。</p>
