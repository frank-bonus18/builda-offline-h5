<h3>events：订阅式回调（App 前后台、暂停面板）</h3>
      <p>请求式 API 是「游戏问、平台答」；<code>events</code> 是「平台推、游戏收」。当前有两个事件。</p>
      <pre><code>const off = Builda.events.on("appVisibility", ({ visible, source }) =&gt; {
  if (!visible) pauseGame();   // App 最小化 / 切后台 / 锁屏
  else resumeGame();           // 回到前台
});
// off();                       // 需要时退订；Builda.events.off("appVisibility") 清空全部订阅

Builda.events.on("pausePanel", ({ visible }) =&gt; {
  if (visible) pauseGameplay();   // 宿主「已暂停」面板弹出（胶囊 ✕ 或 runtime.quit() 弹的同一面板）
  else resumeGameplay();          // 面板关闭且没有退出
});</code></pre>
      <ul>
        <li><strong><code>appVisibility</code></strong>：<code>visible=false</code> = App 最小化/切后台/锁屏（WebView 仍存活），<code>true</code> = 回前台。<code>false</code> 时暂停玩法、计时器、BGM，停掉不必要的网络写入；<code>true</code> 时恢复。<code>source</code> 为 <code>"host"</code>（宿主推送，精确）或 <code>"browser"</code>（WebView <code>visibilitychange</code> 兜底），SDK 已归一并按状态去重，游戏不必区分。</li>
        <li><strong><code>pausePanel</code></strong>：面板弹出时宿主会自己暂停 BGM、停音效，但游戏逻辑在 WebView 里照跑，这个事件让游戏同步暂停玩法与计时。真退出不触发 <code>visible:false</code>。只来自宿主推送，无浏览器兜底。</li>
        <li>两组事件<strong>正交</strong>：面板开着时切后台两个都会触发。按「任一暂停即暂停、全部恢复才恢复」处理，SDK 不做合并。</li>
        <li>都只在状态变化时触发，订阅时不补发当前状态（初始视为前台、面板未显示）。<code>on</code> 返回退订函数；同一 handler 重复 <code>on</code> 只登记一次；某个 handler 抛错不影响其他订阅者。</li>
        <li>引擎侧：Godot 用 <code>builda.gd</code> 的 <code>app_visibility_changed(visible, source)</code> / <code>pause_panel_changed(visible)</code> 信号（通用形态 <code>sdk_event(name, payload)</code>）；Unity 用 <code>BuildaSDK.AppVisibilityChanged</code> / <code>PausePanelChanged</code>（通用形态 <code>BuildaSDK.EventsOn(name, handler)</code>）。都在引擎主线程回调。</li>
        <li>本地 <code>builda dev</code> 测试外壳：「切后台」按钮模拟宿主前后台推送，点胶囊按钮弹出的暂停面板与「继续游戏」模拟 <code>pausePanel</code>；浏览器切标签页走 <code>source:"browser"</code>。</li>
      </ul>

      
<h3 id="online">online：联机（Builda Online）</h3>
      <p>需要多人对战、房间或权威服务器时，联机能力由 Builda Online 提供，与本 SDK 同版本发布：
<a href="https://ai.builda.game/online/index.html">Builda Online 用户文档</a>。在完成本页的 Builda 接入之后，让项目 AI 运行
<code>./.builda-agent/builda sdk install --with-online</code>（CLI 0.4.56 起）：联机 Skill、客户端 SDK、Room SDK 与本地 Mock
都跟随本 SDK 版本安装，之后由 <code>sdk upgrade</code> 一起升级。AI 可阅读的安装说明：<code>https://ai.builda.game/online/releases/0.19.4/setup.md</code>。</p>
      
<h3 id="game-data">Game Data：按游戏共享的数据</h3>
      <p>跨房间共享市场、活动状态、计数或排名时，使用 Online Room 的 Game Data：对象保存共享记录，有序索引用于排序和分页，计数器用于累计数值。个人钱包、背包和进度使用 Player Data，不要把全部玩家数据集中到一个共享对象。</p>
      <p>Game Data 由 Room 服务端调用，不是客户端 <code>Builda</code> 的直接接口。普通读取允许短暂缓存；扣款、领奖等业务判断使用条件更新，不要先读再无条件覆盖，也不要在刷新页面或每个 tick 时反复写共享数据。消息队列当前暂停。</p>
      <p>安装 Online 后，让项目 AI 阅读同版 Skill 的 Game Data 指导，再实现业务。能力与接入说明见 <a href="https://ai.builda.game/online/releases/0.19.4/index.html">同版 Online 用户文档</a>。</p>
