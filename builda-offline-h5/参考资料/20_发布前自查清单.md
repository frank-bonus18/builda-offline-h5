# 发布前自查清单（整合版）

> 本文件整合 `sdk-guide.html`「本地开发与调试 / 发布前自查清单」、`红线汇总`，以及 `online/index.html`、`02_联机安装说明.md` 中的硬性要求。
> 逐条打勾，任一条不通过就不要上传。

## 一、启动与 SDK 引用

- [ ] 游戏最开始就调用了 `Builda.runtime.ready()`，任何启动路径都能调到（dev 看 console 是否有 15 秒警告；真机 30 秒内没收到会被强制关闭）。
- [ ] `index.html` 的 `<head>` 保留根相对外链 `<script src="builda-sdk.js"></script>`，构建工具没有把它当模块打包。
- [ ] 上传 zip 里没有 SDK 文件本身（SDK 由宿主按 manifest 从 CDN 注入）。

## 二、身份与存档

- [ ] 私域字节存档走 `privateKV`；没有用 localStorage / 本地文件自存关键进度。
- [ ] 写入按事件节点（关卡结束、购买成功等），没有定时写；写入频率低于 60 次/分钟。
- [ ] `requestToken` 的 token 只存在内存，未写进 privateKV、文件、URL、日志或存档。
- [ ] 用到 Player Data 时清楚它与 privateKV 是两套数据（Player Data 由 Online 服务器管理）。
- [ ] KV key / payId / rankId 等持久化标识符按 `13_持久化标识符.md` 定名，上线后不随意改。

## 三、界面与平台能力

- [ ] 没有自做的音乐/音效开关、退出按钮、「点击开启声音」引导层（这些由宿主提供）。
- [ ] 关键 UI 避让 `safeArea` 与 `capsuleMenuRect`，用 `--safearea` 实机验证横竖屏。
- [ ] 文本输入走 `showInputPanel`，没有自绘输入框。
- [ ] 页面切后台/回前台用 `events.appVisibility`，暂停面板用 `events.pausePanel`，没有自己轮询 visibility 兜底。

## 四、商业化

- [ ] 支付走 `Builda.iap`（不是 legacy `pay`）。
- [ ] `success` 只表示付钱成功；`grantBy=client` 时按 orderId 在客户端幂等发货并 `claim`，`grantBy=room` 时把 orderId 交给 Room。
- [ ] 广告用 `ad` 激励视频，看完回调才发奖；无宿主时 `HOST_UNAVAILABLE` 不被兜底成成功。
- [ ] 排行榜：manifest 的 `rankBoards` 已声明，代码里的 `rankId` 与之一致，分数范围符合榜单配置。

## 五、资源与包体

- [ ] 使用 `assets` 时没有写死 CDN URL；`res/**` 资源没有重复打进主包；加载失败分支实测过。
- [ ] 构建产物离线自包含，不引用任何外部 CDN；字体优先系统字体，自带字体已子集化。
- [ ] 已关闭 sourcemap，zip 内无 `.map`、`node_modules/`、`.d.ts`、`.env`、VCS 目录。
- [ ] 已跑 `./.builda-agent/builda bundle-check <zip>` 且通过；包体在 200 MiB 以内（大音频先走 `assets upload`）。

## 六、麦克风（用到才勾）

- [ ] Godot：`addons/builda/mic/web/` 已拷进导出目录随 zip 分发；HTML5：`mic/builda-mic-worker.js` 可访问。
- [ ] 声控游戏逐条过：拒绝权限、`MIC_NOT_STARTED`、中断/恢复、开 BGM 时灵敏度。
- [ ] PCM 只在本地实时分析，没有录音留存或上传。

## 七、联机（用到才勾）

- [ ] 只选了一种 Room 语言（TypeScript 或 Rust），没有同时存在两套 Room。
- [ ] `builda.online.json` 已写清 matchKey、公开自动匹配与冻结策略，不是部署时才生成。
- [ ] 两个不同 `local:<player-id>` 客户端跑通加入、状态同步、消息、tick、异常断开、离开。
- [ ] 首个 Ticket 前 `/health` 为 `lifecycle=idle`、`active_rooms=0`；空房宽限期后 `room_generation` 递增。
- [ ] 客户端没有用 `location.hostname` / `localhost` / `127.0.0.1` 判断是否走本地 Mock。
- [ ] 线上只用宿主下发的短期 runtime token（只在内存），本地 `local:` 身份不上线。

## 八、授权与上传

- [ ] 只在需要上传/建草稿/部署时才跑一次幂等的 `./.builda-agent/builda auth`，没有反复 `auth`。
- [ ] 没有擅自 `sdk upgrade`；版本锁保持 `.builda-agent/sdk-version` 原值。
- [ ] 上传前确认这只是同步到 Builda 待发布区，公开发布仍需用户在 App 内走审核流程。
