<h2 id="红线汇总">注意事项与红线汇总</h2>
      <blockquote>
        <p><strong>红线（违反会被拒审或视为事故）：</strong></p>
        <ol>
          <li><strong>不要绕过 SDK 直调宿主桥</strong>——游戏代码禁止接触 <code>window.__cysjHost</code>、<code>flutter_inappwebview.callHandler</code> 或任何底层 App 桥方法。</li>
          <li><strong>token 只在内存</strong>——<code>requestToken</code> 的 token 禁写 privateKV、本地文件、URL、日志、存档。</li>
          <li><strong>麦克风 PCM 只许本地实时分析</strong>——禁止录音留存/上传。</li>
          <li><strong>无宿主不伪造成功</strong>——浏览器环境支付/广告返回 <code>HOST_UNAVAILABLE</code> 是正确行为，不要在游戏侧兜底成「购买成功」。</li>
          <li><strong>不要修改 SDK 分发文件</strong>——<code>builda-sdk.js</code>、<code>addons/builda/</code>（<code>mic/web/</code> 除外）、<code>Assets/Builda/</code> 由 <code>sdk install</code> / <code>builda check</code> 升级时整体覆盖；归你所有的只有 <code>scripts/BuildaClient.gd</code>、mic 分析 worker 目录和你自己的游戏代码。</li>
        </ol>
      </blockquote>

      
<h3>持久化标识符（改动前必须想清楚）</h3>
      <ul>
        <li>privateKV key：<code>^[A-Za-z0-9_:-]{1,64}$</code>；<code>payId</code> / <code>rankId</code>：<code>^[A-Za-z0-9_-]{1,64}$</code>。新代码统一只用字母、数字、<code>_</code>、<code>-</code>。</li>
        <li>改 <code>payId</code> = 改商品映射；改 <code>rankId</code> = 换新榜清历史分。已上线的 ID 不要顺手重命名。</li>
        <li>存量数据的旧 key（如带 <code>:</code> 的）可以继续读写删，不要为格式统一强行迁移。</li>
      </ul>

      
<h3>平台代劳、游戏别做的事</h3>
      <ul>
        <li>登录 / token 管理（<code>whoami</code> 直接拿人）</li>
        <li>音乐/音效开关、暂停/退出页（胶囊菜单 + 平台通用页）</li>
        <li>文本审核与截断（<code>showInputPanel</code> 返回即终态）</li>
        <li>订单创建/查询（不要自拼订单 HTTP；未交付列表用 <code>iap.getPendingOrderIds</code>。补单由游戏自己做，见上方 iap 节）</li>
        <li>广告核销（<code>showRewardAd</code> 返回即结论）</li>
        <li>排行榜最优成绩比较与周期轮换（宿主按 sortType 保留）</li>
        <li>音频解锁（真机无 autoplay 限制）</li>
      </ul>

          <tr><td><code>BUSY</code></td><td>同刻单例的面板已打开（如 input 面板未关重复调）</td></tr>
          <tr><td><code>UNSUPPORTED</code></td><td>非 Web/WebGL 环境调用引擎包装层</td></tr>

          <tr><td><code>VALUE_TOO_LARGE</code> / <code>BATCH_TOO_LARGE</code> / <code>QUOTA_EXCEEDED</code></td><td>privateKV 超限</td></tr>
