放置位置
--------
复制到 HTML5 项目根目录下的 .builda-agent/sdk/web/ 即可；同时写入 .builda-agent/sdk-version = 0.19.4。
游戏 index.html 的 <head> 必须保留根相对引用 <script src="builda-sdk.js"></script>；
SDK 文件本身不进上传 zip，正式运行时由 Builda App 按 manifest 从 CDN 注入。

文件名说明
----------
builda-sdk.js / builda-sdk.d.ts / builda-dev-shell.html / mic/builda-mic-worker.js 是平台硬编码的运行时文件名，
改名会导致注入与引用失败，因此保持英文原名；其余目录与文档均用中文命名。
